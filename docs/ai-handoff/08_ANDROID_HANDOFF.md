# 08_ANDROID_HANDOFF

This document serves as a guide for building the upcoming Android mobile application for MBM ERP.

## Recommended Architecture
- **Framework**: React Native (Expo) or Flutter.
- **Backend Communication**: Since the desktop ERP syncs to Supabase, the Android app should communicate *exclusively* with Supabase via the `supabase-js` or equivalent SDK. It should not attempt to hit the local `localhost:4000` Electron API routes.
- **Authentication**: Supabase Auth (Email/Password or Magic Link) should be implemented to secure the cloud database, replacing the local Desktop PIN system.

## Required APIs & Tables
The Android app will need read/write access to the following Supabase tables:
1. `outgoing_sales` (To view live dispatch tickets)
2. `incoming_boulder` (To view raw material intake)
3. `party_ledger` (To view customer balances)
4. `day_books` (To view daily closing balances)
5. `expenses` (To view or add daily costs)

## Recommended Screens
1. **Dashboard View**: Mobile-optimized version of the main dashboard showing "Today's Sales", "Cash in Hand", and "Total to Receive".
2. **Dispatch Log**: A live-scrolling list of all trucks leaving the quarry today.
3. **Customer Ledger**: Search for a Party and view their current running balance (Receivables).
4. **Expense Entry**: A simple form to submit an `Expense` from the mobile app (e.g. owner buys spare parts on the road).

## Offline Strategy
- The mobile app should ideally function offline when network connectivity is poor at the quarry.
- **Implementation**: Use WatermelonDB or Expo SQLite locally on the device, syncing changes back to Supabase when the network is restored. This mirrors the desktop app's architecture.

## Realtime Strategy
- Use Supabase Postgres Realtime WebSockets (`supabase.channel('public:outgoing_sales')`) to listen for new sales generated by the desktop app.
- This allows the owner to sit at home and watch live sales pop up on their phone the second a truck leaves the weighbridge.

## Potential Future Features
- **Mobile Printing**: Bluetooth thermal printing of receipts directly from the Android app using ESC/POS protocols.
- **GPS Truck Tracking**: Integrating vehicle GPS modules to cross-reference with `OutgoingSale` timestamps.
- **Photo Uploads**: Allow attaching photos of receipts to `Expense` entries (requires Supabase Storage integration).
